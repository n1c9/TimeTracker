# Changelog

## v0.91 — 2026-05-23

### Features
- Day / Week / Month calendar views with smooth navigation
- Drag-and-drop to create, move, and resize time entries
- Snap-to-grid (15-min) toggle — snaps start time, preserves entry duration
- Timer creates freeform entries rounded to nearest minute (no snap)
- Projects with client grouping and color coding
- Task templates for quick entry creation
- Client dropdown in edit entry dialog (filters projects by client)
- Month view shows up to 5 entries per day with +N overflow indicator
- Summary bar chart in week view (hidden in day/month views)
- Filter entries by project (funnel icon)
- Archive/unarchive projects
- Drag-to-reorder projects in sidebar
- Export: CSV and PDF with scope (current view or all)
- Export: By Client grouping option
- Dark/Light theme toggle
- Undo/Redo with 60-level history
- Keyboard shortcuts (? to view all)
- Double-click empty grid to create entry
- Quarter-hour gridlines
- Month view tooltips with entry details
- Fully offline — localStorage persistence
- Mobile: touch gestures, long-press to move, responsive layout
